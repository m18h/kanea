Get started

Three pages take a bare Linux machine to a running service. Read them in order the first time: each one ends where the next begins.

The three steps

  1. Install a node

    Put the kanea binary on a Linux machine and run sudo kanea init. Init installs the runtime, mints the master key, writes the node config and the systemd units, and creates your admin account. Check the requirements first.

  2. Deploy your first service

    Write a short spec, preview it with kanea plan, apply it with kanea run, then check it with kanea ps and kanea logs.

  3. Concepts

    Learn the terms the rest of the docs use: project, service, task and alloc, and what makes the node start, replace or leave alone a container.
