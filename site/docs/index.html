Kanea documentation

Kanea runs containers on one machine. It gives that machine service discovery, load balancing, network policy, TLS, autoscaling, GitOps and backups, which normally take a cluster. It ships as one static binary. You describe a project in one HCL spec, and Kanea keeps the node matching it.

New here? Get started walks the first three pages in order. If you already have a node, Find by task points at the section you need.
